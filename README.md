# Description:

Description:
Tertizz is a mechanical pattern maker that makes use of servo motors to move two tiles, to create various configurations/patterns. Following the aesthetics of "Tertis", the player has to replicate the pattern displayed on - the currently non-existant - led dot matrix display and upon getting the right, recieves points based on the time taken (yet to implement).
